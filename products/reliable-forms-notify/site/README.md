# Reliable Forms Notify — launch site

Static launch/OAuth/Marketplace site for Reliable Forms Notify.

## Intended production hostname

`forms.askouresystems.com`

This reuses the already-owned `askouresystems.com` domain instead of purchasing a second product domain.

## Pages

- `index.html`
- `pricing.html`
- `privacy.html`
- `terms.html`
- `support.html`
- `styles.css`

## Deployment target

Cloudflare Pages. No server-side runtime required.

## Publication gate

Do not use these URLs in OAuth/Marketplace until:
1. Cloudflare Pages deployment is live.
2. `forms.askouresystems.com` is attached and HTTPS is valid.
3. Google Search Console ownership for `askouresystems.com` is verified.
4. `support@askouresystems.com` inbound routing is confirmed, or the support page is updated to a verified address.

## Product facts

Free: 50 notification recipients/month, 1 rule/form.
Pro: $3.99/month or $29.99/year, no app-imposed monthly recipient cap, up to 10 rules/form.
Google daily email-recipient quotas always still apply.
